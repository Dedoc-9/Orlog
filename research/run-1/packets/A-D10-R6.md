## 3. The mechanism

How a claim comes to be held and GROUNDED (read, not run):
- **Agreement comes only from the witness argument.** `agreed = witness.get("dissent_kind") == "NONE" and bool(witness.get("backends"))` (court.py:229).
- **No backends means REFERENCE-ONLY.** When no backend ran, nothing failed to build and nothing was stopped, integrity reads `"CONTESTED" if witness.get("backends") else "REFERENCE-ONLY"` (court.py:238).
- **Held:** `held = hit is None and r["evals"] > 0 and r["trues"] == r["evals"] and agreed` (court.py:288).
- **R8 never touches a refusal at another clause.** `hit` is the court's R8 (court.py:58-78, parameter `r8` at :67-71 and :226). It returns None when the refusing clause is not the claim's (:73). That is why a PREFIX claim survives a refusal at a tick. There is no R6 parameter yet.
- **Grounding:**
  - the claim's channel must be admissible (:96-98; a bare claim's channel defaults to computation, src/orlog/syntax.py:591, and can never be grounded);
  - a ledger line must ratify the claim's own seal (:308-314);
  - `rows[k] = (row, held and ext)` (:319), then the least fixed point over premises (:322), then GROUNDED (:337).
- **Without agreement:** the sandwich reads "VACUOUS (the backends did not all agree)" (:341-342).
- **Where the witness comes from.** `Arbiter.arbitrate` (arbiter.py:246-327) runs each backend in `self.backends` (:269-279). A backend agrees only if its receipt core and its output are byte-equal to the reference's and it exits 0 (:287-289). With zero backends: `dissent_kind` is NONE (:310-311) and `backends` is `{}` (:321). The reference is "the authority … by declaration (not proven; not a vote)" (:324).

**What this means for a v1 run in 1a.** INFERENCE from the lines above:
- No backend runs a v1 law until 1b, so the arbiter's witness has no backends.
- Every claim therefore reads integrity REFERENCE-ONLY, UNSUPPORTED or UNREACHED, and UNGROUNDED, with a VACUOUS sandwich.
- The evaluation line ("true in k of k", REFUTED, R8, UNREACHED) still prints.
- R6's withholding cannot be seen, because the claim is already withheld. A row expecting UNGROUNDED passes whether R6 is right or wrong: DESIGN-BRIEF.md:266-271, H7.
- A row expecting held or GROUNDED (the PREFIX row, rider 2's control) fails outright.

**Does REFERENCE-ONLY follow from the court's own rule?** Mechanically yes: court R1 plus D10's two-commit split produce it with no code change, and it expires by itself once backends exist (court.py:229). D10 still carries three policy choices:
- the split itself;
- not relaxing R1 for v1 laws in 1a;
- REFERENCE-ONLY (no backend attempted) rather than INCOMPLETE (backends attempted and failed).

**Rider 1 already gets around this in tests.** The existing configured witness is `{"dissent_kind": "NONE", "backends": {"reference": {}}}` (tests/court_monotone.py:70, with "The witness is made agreed" at :6-8; research/r8_coverage.py:43). Two side effects of reading such a witness:
- Integrity prints a bare "AGREED" (court.py:232). That is the string the plant `integrity-names-no-backend` treats as a defect (tests/selftest.py:1680-1683).
- In a real 1a reading, the sandwich text says the backends "did not all agree" when none ran. That is a reporting wrinkle for §15.14; nothing here decides it.

**Two notes on rider 2's control and the probes.** Both INFERENCE.
- Rider 2's first control form, "without an active log declaration", is a version-0 law if it has neither a port nor a tick block (§15.0). It can read GROUNDED in 1a with real v0 backends, provided its own seal is ratified: the seal binds the law seal (court.py:171-174). Only the PREFIX-wrapped control is a v1 law. For the pair to differ in one respect only, run both with the configured witness.
- The claims in P12, P16, P29, P31, P33 and P35 have no "by …", so their channel is computation and they can never read GROUNDED, whatever D10 says. Separately, "GROUNDED but not HELD" in P29(a), P31 and P33 contradicts "GROUNDED requires held" (finding 47's disposition, §15.12.2).

## 4. The alternatives

How the labels map:
- The reviewer's A = draft 1's second alternative.
- The reviewer's B ≈ draft 1's third.
- The reviewer's C ≈ draft 1's first, restricted to PREFIX.
- D is mine.

**A. Keep D10; R6's rows wait for 1b.**
- In 1a: R6 is built, if R7 permits, with no non-vacuous row. Or R6 waits for 1b too. A must say which.
- In 1b: the rows run for the first time; real holds and R6's rows arrive together.
- Failure (unexecuted): 1a ships R6 with the pre-doppler trigger, "declares any port" (the DP-4 plant, RULINGS.md:253). Take a tick-only law: `Let n be 0.`, `Each tick…`, `Increase n by 1.`, `We claim that n is positive, by the owner.`, its seal ratified. Correct R6 reads UNGROUNDED. Under REFERENCE-ONLY the planted trigger also reads UNGROUNDED, so the row passes with the plant in place, and the defect is found in 1b at the earliest.

**B. Replace D10: the reference holds claims in 1a; agreement is required from 1b.**
- In 1a: R1 is relaxed for v1 laws (panel's `agreed`, court R1's text), and every v1 claim can read held, and a PREFIX claim GROUNDED, on one execution.
- In 1b: the exception is withdrawn, and the same law and log can drop from held to not held.
- Failure: the reference itself can be wrong. The self-test arbitrates `contested_true.orl` with `reference_truncates_quotient` (tests/selftest.py:1428-1438): R1 keeps the claim UNSUPPORTED and UNGROUNDED, and the plant `held-ignores-integrity` (:1451-1455) shows it would otherwise read WELL-FOUNDED and GROUNDED. For v1 laws in 1a, B is that plant: no backend exists to dissent. The arbiter's REFERENCE-DISSENT kind exists for this case (arbiter.py:303-305).

**C. Lift D10 only for R6-authorized PREFIX rows.**
- In 1a, two readings of C:
  - If it governs real readings: a PREFIX claim is held on the reference alone, and nothing else is.
  - If it governs only test rows: it collapses into D, but it leaves rider 1's ungrounded rows out.
- In 1b: as B, limited to PREFIX claims. The PREFIX boundary may also be ruled differently between 1a and 1b.
- Failure: C's domain is undefined while findings 3-5 are open.
  - P13 (REPORT.md:526-535) is exempt under the static-closure proposal and not exempt under R6's words.
  - P29(a), P31 and P33 depend on the rider's reach (open question 3).
  - B's failure (a wrong reference with no dissent) applies to PREFIX claims too. The licence answers "does this claim depend on the log?", not "did the reference compute it correctly?".

**D (preferred). Rule D10's court clause with a scope sentence: real readings stay REFERENCE-ONLY; R6's rows, the PREFIX row and their controls run in 1a with the configured witness.**
- In 1a: R6's withholding, its licence and the PREFIX settlement are exercised non-vacuously, with plants. A real v1 reading holds nothing and prints the provenance line.
- In 1b: the rows are unchanged (rider 1 still applies), and real readings start to hold claims with no code change for D10's expiry. One row on a real agreed run could be added: PROPOSED, not required.
- Failures:
  1. If a configured panel's output escapes its row into `court_artifact` (court.py:364-380) or a report, it states an agreement no execution produced. That breaks the authority rule (ROUNDS.md:407-409) and §15.11's "never reported as validity".
  2. The rows show the rules only, given the reference's receipt. They cannot catch a v1 reference defect in that receipt, for example a prefix refusal reported at tick 1.
  3. Extending rider 1 to the PREFIX row and to the controls is my reading of "structurally paired". If the owner meant real agreement there, D under-delivers until 1b.

## 7. Falsifier

The recommendation is wrong if any of these is seen:
1. A 1b run in which every backend agrees, and some R6 row's evaluation, support or grounding differs from its 1a configured-witness reading of the same law and log. Only the integrity string should differ: panel reads the witness only at court.py:229-238 and 339-342.
2. A real 1a reading (`orl.py court`) of a v1 law that holds a claim or reads GROUNDED.
3. A configured-witness reading that appears outside its row without saying the agreement is configured.
4. An R6 plant that survives the 1a rows: the narrow wording, "declares any port", clause position, "before the first port declaration is enough", or "withholds every claim of a refused run".
5. A ruling by the owner that "historically held" requires held in real 1a readings, or that E2 replaces R1. Either makes D unfaithful.

**What D does not show:** that the 1a reference computes v1 claim lines or cuts correctly (only agreement in 1b can), or that R6 is complete (it is sound, not complete: RULINGS.md:258-260).
