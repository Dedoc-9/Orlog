Scenario (the graybox, rules 1): a body on a cell-center line at yaw 0, forward held, 125 ticks.
  world: cells 1 wide in x, 8 deep in z, 1 m each; tops by z-cell = [0, 0, 0.5, 0.5, 0, 0, 0, 0].
  start: x = 0.5 (centre of x-cell 0), z = 7.52, feet = 0.0, vy = 0.0, on the ground, yaw 0, pitch 0.
  input: forward held every tick (no turn, no strafe, no jump).

The walk at yaw 0 is trig-free in value: sin 0 = 0, cos 0 = 1, hypot(0, 1) = 1, all exact in the graybox's
fdlibm, so forward is a pure move in -z of mz/length * speed * TICK = -1.0 * 6.0 * TICK per tick, and the x-move
is move(0, 0) (no effect). No cell is ever a wall for this body (a 0.5 ledge is at most feet + step, so is_blocked
is false and move never halves): the walk is z <- z + dz each tick with dz = -(6.0 * TICK).

world.ground on this line reduces exactly to a one-interval test on z (radius 0.35, cell 1.0, x centred):
  ground(z) = 0.5  if and only if  1.65 < z < 4.35 ;  else 0.0.
(The ledge z-cells 2 and 3 are "near" the body's radius exactly on that open interval; the circle-rectangle
overlap and the interval agree at every tick because the crossings fall mid-step, below.)

Constants: TICK = 1/120, gravity = 20, speed = 6, step = 0.55.
Per tick, in order: turn (nothing); walk (z += dz); fall (vy <- vy - gravity*TICK; feet <- feet + vy*TICK);
land (feet <- ground, vy <- 0, grounded, when feet <= ground OR (was-grounded AND vy <= 0 AND feet - ground <= step)).
